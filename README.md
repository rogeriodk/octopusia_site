# OCTOPUS IA Site

Repositório oficial do site e portfólio interativo da OCTOPUS IA.

## Branches

- `main`: versão estável/aprovada.
- `homologacao`: desenvolvimento e homologação contínua.
- `homologacao-reports`: relatórios sanitizados de CI, smoke, regressão e auditoria.

> A branch `main` não recebe desenvolvimento direto. Mudanças da aplicação são feitas em `homologacao` e só chegam à produção após homologação humana.
